# 0014. 纯 JSON 声明式原子公式与计算管道

- **状态**：Accepted
- **日期**：2026-10-18
- **替代**：ADR-0001；覆盖 ADR-0005 中管道默认值依赖 Python 常量的约定，及 ADR-0013 中应用层相态拦截的约定。
- **继续有效**：ADR-0004 的人工确认状态机、ADR-0011 的节点求解方向与成果契约、ADR-0013 的 IAPWS-95 物性算法。

## 背景

原先 Python 公式和场景模块依赖 import 触发注册，扩展工具还接受 Python 构造式模板。场景源码、运行时定义和数据目录形成多条加载路径；数值范围及相态审查阻断了探索性工况。重构规范见 `.scratch/json-pipeline-formula-refactor/spec.md`。

## 决策

1. 原子公式存放于 `formulas/<中文计算含义>_<英文标识>.json`。代数公式声明表达式和引脚，继续由受限数学语法解析器与 SymPy 求解；经验公式通过 `handler` 引用 `core/handlers.py` 的静态白名单。JSON 不指定模块路径，不执行 Python 模板。
2. 场景存放于 `pipelines/<pipeline_id>.json`，内联全部输入、常量、默认值及 DAG 映射。`core/catalog.py` 在启动时先递归加载公式、再加载管道，验证引脚、单位、引用、拓扑及唯一 ID。无 Python 场景导入或文件回退。
3. MCP 注册工具使用严格 Pydantic JSON schema，拒绝未知字段、错误类型及未注册 handler；经验公式的引脚名称与单位须匹配 handler 契约。验证后原子写入资产文件并即时注册。前端保留原有编辑载荷，由后端转换为同一标准公式 JSON；会话草稿和布局继续保存在数据目录。
4. `min_value` / `max_value` 是前端参考元数据。旧输入约束可往返保存，其范围与大小关系均不拦截数值。移除熔盐温区及水汽相态的应用层审查。有限数值允许进入计算；除零、非有限实数结果和 IAPWS-95 自身的不可求解状态仍报告错误，不夹值、不伪造物性或引入近似替代。
5. ADR-0004 完整有效：场景提议、场景确认、参数检查、参数确认、执行计算的守卫全部保留。注册、打开编辑器、参数更新均不授予计算权限；修改算子或拓扑撤销原授权。`core/state_machine.py` 不作修改。
6. `ui_prototype.html` 与 `ui_editor.js` 保持原样，会话 API、变量单位、布局数据及节点求解方向保持兼容。目录工具另提供完整 JSON `definition`，供 Agent 检查与复用。

## 后果与验证

- 新增 JSON 文件在服务下次启动时自动发现；MCP 注册即时生效，手工编辑磁盘文件后需重启。资产根目录默认使用项目绝对路径，可用 `THERMAL_CALC_ASSET_DIR` 隔离测试或部署。
- 历史 `.data/` 公式与管道资产不在本次迁移范围；不会隐式转换或重写工程师数据。需要保留的历史资产须单独审核并转为新 JSON 契约。
- 保留旧公式 ID 与引脚标识，以兼容节点和前端；显示名称与文件名按物理计算含义命名。已有别名仍各自对应独立 JSON。
- 迁移前提交 `fedcccb8f317c541d1a37f2545f5b607c58d6b68` 的两条默认场景全部输出存于 `tests/fixtures/baseline_outputs.json`，新引擎以严格相等断言核对。其他回归覆盖反算、范围放行、相态跨界、无授权计算拦截、JSON 注册与进程重启，以及现有前端交互。

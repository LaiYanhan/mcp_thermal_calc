# 声明式计算管道与标准公式代码模板

状态：已被 [ADR-0014](0014-pure-json-declarative-formulas-and-pipelines.md) 替代。以下保留为历史决策。

为了满足“AI 不得私自计算任何值”的核心红线，同时赋予系统面向新场景的自适应扩展能力，我们决定所有场景计算管道统一采用声明式有向无环图（DAG）结构存储于 `pipelines/` 目录；当新场景缺少物理公式时，AI 只能按照统一的代码模板生成原子公式文件存入 `formulas/`，且必须经人工审核确认后才能被引擎注册调用。

## Considered Options
- **由 AI 动态生成并直接执行 Python 脚本**：灵活性最高，但存在致命的计算幻觉、变量混淆和安全漏洞风险，违背企业质量红线。
- **纯静态写死所有计算场景**：无法应对企业未来在源侧、网侧、工业园区等几十种衍生场景的扩展需求。
- **声明式 DAG 组装 + 模板化公式扩展（已采纳）**：在杜绝未受控运算的前提下，保留了通过规范模版无缝吸纳新场景与新公式的工程扩展性。

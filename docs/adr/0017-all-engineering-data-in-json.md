# 工程常量、设备规则与熔盐资料全量迁入 JSON

状态：Accepted。用户在通用数据核心完成后明确要求迁移 `constants/` 内全部数据，所有引用改用 JSON，禁止硬编码；此要求扩大此前未迁移历史数据的范围。

## 决策

- 删除 `constants/` 下全部 Python 文件。原默认参数的值、单位、含义与参考范围完整保存到 `default_parameters.json`；设备档位、整定刻度、功率因数、阶梯价格和电气单价保存到 `equipment_catalog.json`；两种熔盐的名称、别名、组分、温区、默认温度、关联式系数、幂次及单位保存到 `molten_salt.json`。
- 资料 JSON 是可复用的数据模板。ADR-0014 的自包含场景继续有效：使用时将所需单值量内联到 `required_inputs`，将表内联到 `data_tables`，节点通过 `data_map` 绑定。运行不读取共享资料去替换已确认快照，也不建立强制公共注册中心或热加载。
- 删除设备专用处理函数。四个设备公式 ID 保留，改用 `data.fixed_step` 或 `data.discrete`，数值引脚统一为 `value` / `result`。两条默认管道的熔盐订货节点及表绑定同步迁移，产出变量保持原名。旧自定义管道和草稿须同步引脚及数据绑定后重新确认，不增加 Python 兼容回退。
- 变压器数据端口的输入输出均为 MVA。有功功率通过 JSON 代数公式 `electrical.apparent_capacity`，配合场景声明的功率因数先换算为视在容量。沿用已确认的通用表边界语义：超界取首末行，取消旧函数中超过最大档位后按固定倍数组合的隐式逻辑；多台组合须另行明确建模。
- 新增通用 `data.correlation`，按 `sum(coefficient * value ** power) / divisor` 求值，读取声明的有限系数、幂次和非零除数。八种历史熔盐关联式及三种阶梯造价均由 JSON 原子公式引用通用规则，无材料名、设备名或场景 ID 特判。原始温区及关联式说明保留为参考资料，不增加工况拦截。
- 资料迁移不自动给默认场景增加物性或造价步骤。需要时按已有 MCP 注册、场景提议、人工确认及正式执行流程组合。专门的 IAPWS95 算法保持原样；状态机、确认守卫、预览隔离和 Skill 详细业务流程不改。

## 验证边界

迁移前保存独立物性数值基线，并逐项比对原默认参数、容量序列、造价段与物性元数据；八个关联式通过符号等价检查。通过公开 MCP 工作流验证设备整定、所有造价段、全部物性关联式及仅修改 JSON 的扩展，复用重启恢复、预览隔离和原场景完整数值基线回归。发布代码无 `constants` Python 导入或运行回退。

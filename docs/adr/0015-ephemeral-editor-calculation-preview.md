# 阶段 02 的临时预览计算

## 背景

工程师需要在阶段 02 核对参数时直接查看计算数值。用户明确限定：不得修改状态机；预览不代表正式计算完成，也不授予 AI 提供正式完整成果的权限。

## 决策

场景确认后，阶段 02 提供“预览计算”，正常模式与调试模式共用。页面将管道与当前参数快照提交给独立的 `POST /api/preview_calculation`；后端复用严格 JSON 校验与现有管道执行引擎，返回单独的 `preview_result`，禁止响应缓存。

接口不接收会话 ID，不读取或写入会话，不调用工作流管理器，不保存管道、参数、授权或结果，也不新增 MCP 工具。接口本身是无状态的快照计算，阶段限制由编辑器控制；沿用现有本机同源写入检查。页面只在内存中显示带明确提示的预览，未保存的参数保持未保存。参数、管道、公式、会话状态或正式结果变化后，旧预览失效，过期请求的响应不显示。

本决策为 ADR-0004 中“未经确认不得最终计算”的原则补充独立的页面预览用途：正式计算的状态机、人工确认守卫和 MCP 返回边界保持原样。预览值不进入 `calculation_result`，不代表授权或流程完成，AI 仍须按原流程取得人工确认并调用正式计算工具。

## 验证

HTTP 回归检查预览成功、失败及正式计算后再次预览均不改变会话，并验证正式 HTTP/MCP 计算仍被守卫阻断。前端回归检查未保存参数、阶段限制、错误提示和过期响应；浏览器验证编辑参数后点击预览的实际交互。

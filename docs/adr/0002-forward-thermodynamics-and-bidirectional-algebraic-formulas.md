# 单向热工物性查表与双向代数符号求解分层

针对业务中“已知任意变量推导未知变量”的需求，我们决定系统公式内核明确解耦为两类：纯代数方程通过符号引擎（SymPy）支持任意方向的解析逆推求解（$a,b \Rightarrow c$ 或 $a,c \Rightarrow b$）；而水蒸气焓值等依托 IAPWS-IF97 物性库的复杂状态方程仅支持单向正向查表（$(P, T) \Rightarrow h$），不支持也不需要符号逆解。

## Considered Options
- **全公式符号逆解**：IAPWS 状态方程为非线性经验复杂公式，符号求解器无法求出解析反函数，强行使用会导致系统崩溃。
- **全公式黑盒仅单向执行**：无法满足用户在不同工程边界条件下灵活逆推输入变量（如由目标功率反推蒸汽流量）的实际设计需求。
- **代数符号逆解 + 物性单向查表（已采纳）**：技术边界最清晰，兼具物理真实性与计算灵活性。

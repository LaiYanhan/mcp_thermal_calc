# 原生扁平DAG渲染、避障走线与行内增删算子交互规范

为了彻底消除界面视觉堆料、使工程师聚焦于热工物理逻辑与参数文本，我们决定：废除一切人造工段外壳，画布直接 1:1 映射流水线原生扁平步骤拓扑；连线引擎强制执行通道避障算法，严禁线缆与卡片相交重叠；视觉风格切换为以文字可读性为中心的极简暖白基调与低饱和柔和四色标体系；交互上全面引入连线行内插点（`+` 手柄）与卡片即时删除能力。

## Considered Options
- **保留宏观工段大卡片分组**：虽具备阶段感，但与 Pipeline 扁平的 `steps` 数据结构脱节，增加了无谓的嵌套方框和视觉噪音，被用户明确否决。
- **两点直连贝塞尔曲线**：算法简单但在多节点场景下不可避免地横跨穿透卡片文字，导致严重遮挡。
- **原生扁平节点 + 正交通道绕行 + 行内插点交互（已采纳）**：完全契合用户手绘构图，布线规整绕行不重叠，赋予用户如同节点图般的直接插拔编辑体验。

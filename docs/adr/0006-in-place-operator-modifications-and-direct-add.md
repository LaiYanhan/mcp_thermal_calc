# 算子原地修改与直接新增机制

在可视化管道编辑器的算子修改设计中，用户明确拒绝了“自动分流克隆为自定义算子版本”的隐式复杂机制。系统决定：若用户在界面上直接修改某个原子算子的数学公式或内部逻辑，该修改直接全局作用于该算子；若用户需要差异化算法，则通过界面上的“新增算子”按钮明确创建新算子。以此保持概念模型极其直观、避免冗余分支膨胀。

## Considered Options
- **隐藏式版本分支与局部克隆**：虽然隔离了潜在风险，但引入了版本冲突、多份同名算子、选择混乱等不必要的系统复杂性。
- **算子原地修改 + 显式新增算子（已采纳）**：完全符合工程“所见即所得、错了就全局修”的直接直觉，新增需求通过显式操作完成，模型最精炼。

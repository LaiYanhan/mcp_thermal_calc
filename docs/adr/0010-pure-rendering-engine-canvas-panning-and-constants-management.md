# 纯净管道渲染引擎、画布平移与常量节点统一管理

为确保前端严格作为底层 Pipeline 的纯净图形渲染与交互编辑引擎，杜绝任何假造的演示数据与无用功能堆砌，我们决定：
1. **全局画布平移（Canvas Panning）**：支持点击画布空白区域平移整个图纸视图，与节点卡片拖拽分层解耦；
2. **常量作为一等公民节点**：将工程常量（如各类设备效率、物性比热容、设计裕量）全量纳入统一的节点管理体系，支持拖拽定位、数值微调与动态添加；
3. **数据驱动严谨对齐**：前端彻底剔除虚构的外壳与非业务出参，严格仅渲染和持久化管道内部真实存在的入参引脚、原子算子、常量参数与出参结果。

## Considered Options
- **仅拖拽节点卡片，画布视口锁死**：当工程图元向四周扩展排布时，边缘节点容易滑出视口难以观察，平移画布是工业图纸的标准交互。
- **将常量仅硬编码在算子卡片内部**：无法直观呈现公共常量的共享流动关系，常量作为独立可拖拽节点更为清晰易读。
- **纯净引擎架构（已采纳）**：前端只做管道数据模型的解析、排版、展示与修改回传，不承载任何脱离 Pipeline 定义的伪功能。

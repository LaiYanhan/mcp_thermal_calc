# 自由拖拽画布、多目标输出拓扑与悬浮按钮精简

为满足工程师根据实际工程图纸自由排布图元的直觉需求，同时支撑未来复杂多分支工程（一个流水线同时输出设备选型、储能物理量、物料平衡、经营毛利与碳核算等多维指标），我们决定：
1. 画布全面放开所有卡片节点的自由拖拽定位（Drag-and-Drop），连线引擎在拖拽过程中实时重绘重轨；
2. 彻底移除右下角冗余的大圆 `(+)` 悬浮按钮，算子添加与插入收敛至顶部动作栏与节点上下文菜单；
3. 破除“单输出收敛”的假定，流水线在拓扑上正式支持多末梢独立输出节点（Multi-Terminal Outputs），并在界面上统一支持多维度成果的分布展现与汇总。

## Considered Options
- **严格网格自动强对齐，禁止拖拽**：虽然保证了算法排版整洁，但剥夺了工程师自由布局、分组标注与按工序摆放的自由度，被用户明确否决。
- **单终点汇聚模型**：强行将所有分支合并到一个最终大方框，无法应对同时测算多套机组选型、储能罐容、碳减排与财务等多目标场景。
- **自由拖拽 + 动态实时走线 + 多分支独立终点（已采纳）**：完全契合真实工业组态与工程测算软件的标准交互范式。

# 0012. 拓扑分流波浪排布与微型参数胶囊视觉重构规范

- **状态**: Accepted
- **日期**: 2026-10-16

## 背景与问题

系统原先前端画布存在两个核心痛点：
1. **尺寸混杂与视觉失焦**：工程常量与输入工况采用与多引脚复杂公式算子完全均一的 260px 宽大卡片，且卡片充斥英文字段，造成视觉噪音极大，核心计算主干被淹没；
2. **蛇形网格与单一线性穿模遮挡**：原网格布局强行将节点按数组顺序蛇形折返或横向一字排开。当下游出现跨步引用（如 SGS功率直连设备选型、电加热功率连至电耗与变压器）时，连线被迫从中间卡片正前方横切穿透，直角折线挤压共线形成混乱黑条。

## 决策

我们决定：
1. **微型参数胶囊规范（Micro Parameter Capsule）**：
   - 输入与常量卡片全面收缩至 130px 极简微型胶囊（高度约 46px），彻底移除卡片正面的英文字段（仅保留中文描述、录入框与物理单位）；
   - 保留全部底层数据属性与事件接口（`data-parameter`、`data-out` 等），确保功能与 API 绝对无损。
2. **拓扑分流波浪布局（Topological Fork Wave Layout - 方案2）**：
   - **主干中轨（Y = 200px）**：能量与比焓核心物理因果链沿水平中轴顺畅推进；
   - **支线下沉轨（Y = 440px / 660px）**：设备选型整定与经营物料指标算子就近垂直下悬，形成自然树状河流分流；
   - **输入置顶（Y = 20px ~ 40px）**：输入参数就近紧凑挂载于对应算子上方，消除远距飞线；
   - 彻底废除蛇形网格与单一水平死板排布。
3. **四色语义带箭头贝塞尔走线与悬停高亮**：
   - 连线采用自适应平滑贝塞尔曲线，配备末端物理方向箭头；
   - 严格沿用绿（输入）、黄虚线（常量）、蓝（算子输出）四色语义规范；
   - 增加悬停聚焦交互（移入节点高亮其上下游拓扑链路，其余连线柔化降噪）。
4. **公式与文本严格沿用中文**：
   - 算子公式与引脚全部严格读取后端既有的中文符号表达，不改变任何已有的接口、字段或文字。

## 后果与权衡

- **积极影响**：
  - 核心算子成为绝对的视觉重心，连线完全消除同轴穿刺与重叠粗黑线问题；
  - 树状物理流向契合热工工程师直觉，设备选型与经济收益分布清晰。
- **负面影响/风险**：
  - 用户需要通过平移画布查看沿水平与纵向自然展开的图纸，但系统已内置原生空白拖拽平移与滚轮导航支持。

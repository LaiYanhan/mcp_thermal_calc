# 节点锚定式算子自由插拔、折返走线与高锐度排版规范

为了提供符合工业流程直觉的交互体验，彻底摒弃细碎线缆微按钮，我们决定：算子的插入、删除与替换操作全面锚定于节点卡片与侧边属性抽屉（提供明确的【前插算子】、【后插算子】、【删除】与【替换】动作）；删除算子时对下游受影响引脚实施软告警与一键重接重定向；长流水线采用保持字号恒定的折返流动（Serpentine Flow）与专用通道布线；全局界面切换至高锐度、深炭黑高对比度字体排版，杜绝纤细灰字与模糊渲染。

## Considered Options
- **线缆悬浮微按钮插点与浮动角标**：目标过小、极易误触，且脱离具体的算子逻辑上下文，已被用户明确否决。
- **全局缩放视口适配长流程**：流程越长字号缩得越小，导致工程师无法看清参数数值。
- **节点工具条/抽屉插拔 + 折返流动 + 锐利文字（已采纳）**：完全契合真实工程流程图操作习惯，字号大而锐利、连线通道独立、插拔逻辑自洽容错。

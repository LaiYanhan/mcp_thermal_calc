# 选型与造价逻辑原子公式化与管道一体化组装

系统不建立独立抽象的“选型造价元框架”，而是将设备离散选型规则（如 SGS 向上圆整、变压器规格查表）和阶梯单价造价规则全部平铺抽象为标准的“原子公式（Atomic Formula）”节点，并在各场景的计算管道（Pipeline）中与热工物理公式串联为一条端到端流水线。

## Considered Options
- **建立分层的热工/选型/造价三层元框架**：虽然概念隔离度高，但增加了不必要的抽象层，割裂了工程人员直观的计算流水线体验，过度设计。
- **全平铺原子公式与管道流水线一体化（已采纳）**：完全遵循业务原图逻辑，每个选型台阶与造价分支作为一个纯净公式节点，流水线一目了然且易于扩展。

# 工程数据扩展与新增算法的职责边界

状态：Accepted；本条记录参数与常量重构访谈中已确认的职责边界，不表示迁移已实施。

参数、工程常量、设备档位、阶梯价格及物性拟合系数等同类工程数据，应能通过 JSON 新增或修改，并复用已有的计算方法。现有方法无法表达的新算法，允许开发新的 Python 处理函数；通用执行引擎负责解释声明和调度算法，不因新增同类数据加入业务名称或设备型号特判。这样保留了工程师和 AI 维护数据的能力，也允许专门物性算法继续以程序实现。

参数与单值工程常量采用各场景独立定义的方式，继续内联于管道 JSON，不建立必须注册的公共参数库；同名量在不同场景可以具有各自的默认值和参考范围。这延续 ADR-0014 的管道自包含约定。

本轮范围是提供可由 JSON 配置的通用核心能力，不迁移未使用的历史阶梯造价、熔盐物性关联式，也不为现有场景加入这些业务节点；相应业务 JSON 由使用者自行定义。暂不实现前端整表编辑。

核心通过配置支持向上整定、向下整定、四舍五入和分段取值。查表输入超出表的输入范围时直接采用相应首行或末行结果，不增加表外告警、审批或额外防护流程；此处的表边界与参数参考范围是不同概念。本轮不实现前端修改 JSON 的能力，不增加自动热加载机制。

固定步长与不等距档位均支持上述三种整定方式。四舍五入选择最近候选值，中点采用半入规则（例如 2.5 取 3、-2.5 取 -3），不使用取偶数舍入。用户明确要求不扩展特殊情形和额外警告机制。

此决策不改变状态机、人工确认守卫及正式计算授权流程，也不删改 SKILL 的详细业务流程和各类注意事项。上述范围已在访谈中确定；本文件记录设计决定，不表示核心代码已经实现。

# 独立工程常量与默认基准参数配置目录

更新：管道默认值现由 JSON 内联，见 [ADR-0014](0014-pure-json-declarative-formulas-and-pipelines.md)；物性资料与设备规格规则仍保留于 `constants/`。

为避免在计算代码或公式中硬编码物性参数与工程默认值，同时便于工程师维护和对照历史设计，我们设立独立的 `constants/` 目录。该目录集中管理工程基准默认值、熔盐热物理物性方程表、离散设备规格档位与阶梯造价规则，所有字段均严格附带参考 Excel 原表的完整中文注释与物理单位。当用户未指定某输入参数时，系统自动拉取该目录配置作为默认值呈现给用户确认。

## Considered Options
- **在各个公式节点内内联默认值**：导致参数分散在数十个文件中，无法统一审阅，修改基准参数时极易出现不一致。
- **将所有常量存入无类型的 JSON/YAML**：缺乏 Python 类型提示和符号引用，容易丢失详尽的中文工程解释。
- **独立 Python 常量数据模块（已采纳）**：既具备严谨的代码类型注解与详尽中文工程释义，又能被公式库和 MCP 状态机统一动态检索。
